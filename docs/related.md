# Related projects

Other tools from the same ISP work:

- [statix](https://github.com/GeiserX/statix): a web app with network statistics graphs for an ISP.
- [router-express](https://github.com/GeiserX/router-express): sets up client routers automatically and keeps several databases in sync.
- [ScriptPoblar](https://github.com/GeiserX/ScriptPoblar): adds a whole network of devices to CRM Control in parallel.
- [genieacs-container](https://github.com/GeiserX/genieacs-container): the Helm chart and container for GenieACS, the TR-069 server that manages client routers remotely.
